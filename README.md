# Electronics Network Platform

Django REST API платформа для управления иерархической сетью по продаже электроники.

## 🚀 Особенности

- **Иерархическая структура** сетей (Завод → Розничная сеть → Индивидуальный предприниматель)
- **REST API** с полным CRUD для поставщиков
- **Автоматическое вычисление уровня** иерархии
- **Фильтрация** объектов по стране
- **Права доступа** только для активных сотрудников
- **Админ-панель** с расширенными функциями

## 📋 Выполненные требования

### Модели данных
- ✅ Модель сети с 3 уровнями иерархии
- ✅ Связь с поставщиком (ForeignKey to self)
- ✅ Контакты (email, страна, город, улица, дом)
- ✅ Продукты (название, модель, дата выхода)
- ✅ Задолженность перед поставщиком
- ✅ Время создания (auto_now_add)

### Админ-панель
- ✅ Ссылка на поставщика в деталях объекта
- ✅ Фильтр по названию города
- ✅ Admin action для очистки задолженности

### DRF API
- ✅ CRUD операции для модели поставщика
- ✅ Запрет обновления поля "Задолженность" через API
- ✅ Фильтрация объектов по стране
- ✅ Права доступа только для активных сотрудников

## 🛠 Технологии

- Python 3.12+

- PostgreSQL 10+

## 🏗 Архитектурные решения

### Вычисление уровня иерархии
Уровень вычисляется динамически через свойство `level`, а не хранится в БД, как требует задание:
```python
@property
def level(self):
    if self.supplier is None:
        return self.FACTORY
    return self.supplier.level + 1
```
### Создание NetworkNodes через API

Создание сложных объектов со связями (контакты, продукты) реализовано через админ-панель,  
а API предоставляет базовый CRUD для соответствия требованиям задания.

## 🔧 Установка и запуск

1. **Клонировать репозиторий**
2. **Установить зависимости**: `pip install -r requirements.txt`
3. **Настроить базу данных** в `.env`
4. **Выполнить миграции**: `python manage.py migrate`
5. **Создать суперпользователя**: `python manage.py createsuperuser`
6. **Запустить сервер**: `python manage.py runserver`

## 📊 API Endpoints

- `GET /api/network-nodes/` - список всех поставщиков
- `GET /api/network-nodes/?contact__country=Russia` - фильтрация по стране
- `GET /api/contacts/` - список контактов
- `GET /api/products/` - список продуктов

## 🔐 Аутентификация

Доступ к API имеют только аутентифицированные активные сотрудники.
